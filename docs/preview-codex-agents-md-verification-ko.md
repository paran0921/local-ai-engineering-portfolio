# Preview: Codex AGENTS.md 자동 로딩 및 작업 제한 검증

[English version](preview-codex-agents-md-verification-en.md)

- 작성일: 2026-11-16
- 문서 상태: Preview
- 범위: Laravel 프로젝트에서 수행한 Codex 세션 2건의 증거
- 검증 상태: 지침 자동 로딩과 제한된 읽기·테스트 작업은 확인했으나, 실제 코드 수정 중의 준수 여부는 아직 미검증

## 검증 목적

저장소 수준의 작업 지침은 에이전트의 세션에 전달되고 실제 작업 과정에서 적용되는지 확인할 필요가 있다. 이 Preview는 2026년 11월 16일 두 차례의 Codex 세션에서 관찰한 내용을 소개한다. 모든 상황에서 지침 준수가 보장된다고 주장하지 않는다.

## 확인된 내용

### 1. AGENTS.md 자동 로딩

첫 번째 세션의 Codex Rollout(Codex 세션의 JSONL 실행 기록)에는 프로젝트 `AGENTS.md` 지침이 세션 컨텍스트에 포함되어 있었다. 구조화된 메타데이터는 해당 내용을 `agents_md.instructions`(AGENTS.md 지침을 나타내는 컨텍스트 항목 유형), 출처를 `agents_md`(지침 출처를 나타내는 메타데이터)로 표시했으며, 세션의 world state(`world_state`, 세션 실행 상태 메타데이터)에도 적용 지침이 기록되어 있었다.

이는 해당 세션에 지침이 자동으로 제공되었다는 증거다. 다만 이 사실만으로 Codex가 디스크의 파일을 별도로 열었다거나, 주입된 내용과 디스크 파일이 바이트 단위로 동일했다고 볼 수는 없다.

### 2. 후속 세션의 직접 읽기 및 사전 조사

두 번째 세션에서는 자동 제공된 지침뿐 아니라 `AGENTS.md`를 직접 확인하는 명령도 기록되어 있었다. 테스트 실행 전 프로젝트 설정, 관련 라우트, 애플리케이션 코드, 뷰, 테스트, diff 및 Git 상태를 조사했다.

기록된 사전 조사 단계에서는 파일 수정이나 테스트 실행이 이루어지지 않았다.

### 3. 승인된 테스트 실행

승인된 실행 명령은 다음과 같다.

```powershell
php artisan test --filter=PostIndexTest
```

Rollout에 기록된 결과는 다음과 같다.

| 항목 | 결과 |
|---|---:|
| 종료 코드 | 0 |
| 통과 테스트 | 7 |
| 실패 테스트 | 0 |
| 건너뜀 | 0 |
| Assertions | 21 |
| 실행 시간 | 16.41초 |

동일한 `created_at` 값을 가진 게시물에서 ID 내림차순 정렬을 확인하는 테스트도 출력에 포함되어 있었다.

### 4. 제한된 범위의 Git 상태 비교

테스트 전후 다음 명령의 결과를 비교했다.

```powershell
git status --short -- app tests routes resources
```

기록된 두 결과는 동일했다.

이는 해당 세션에서 지정한 네 경로의 Git 상태가 유지되었다는 근거다. 저장소 전체 파일의 바이트 단위 동일성을 입증하거나 외부 프로세스의 변경 가능성까지 배제하는 것은 아니다.

## 증거 기반 평가

| 항목 | 평가 |
|---|---|
| AGENTS.md 지침의 세션 자동 제공 | 확인됨 |
| 후속 세션에서 AGENTS.md 직접 읽기 | 확인됨 |
| 작업 전 프로젝트 조사 | 기록으로 확인 |
| 승인된 테스트 실행 | Rollout에서 확인 |
| 테스트 결과: 7 tests, 21 assertions | 기록된 출력에서 확인 |
| 지정한 네 경로의 Git 상태 유지 | 기록된 출력에서 확인 |
| 실제 코드 수정 중 지침 준수 | 아직 미검증 |
| 저장소 전체의 바이트 단위 보존 | 입증되지 않음 |

## 이번 Preview에서 주장하지 않는 사항

- 모든 향후 Codex 세션에서 지침 준수가 보장된다는 주장
- 실제 소스 코드 수정 과정에서도 지침을 준수했다는 주장
- 저장소의 모든 파일이 변경되지 않았다는 주장
- CLI와 백그라운드 서비스의 버전 차이가 이번 동작에 영향을 주었다는 주장. 인과관계는 확인되지 않았다.

## 다음 단계

다음으로 유용한 평가는 변경 허용 파일, 성공 기준, 테스트 명령 및 중단 조건을 사전에 정한 작은 코드 수정 작업이다. 작업 후에는 diff, 테스트 출력, 작업 전후 상태를 각각 별도 증거로 검토해야 한다.
