# 로컬 AI 변화 대응 전략 및 에이전트 평가 이력

- 작성일: 2026-10-15
- 범위: 로컬 AI 아키텍처, 코딩 에이전트 운영 전략, 향후 평가 계획
- 상태: 논의 내용 기록 완료. 대체 도구 검증 및 실제 적용은 미완료

## 1\. 작성 목적

빠르게 변화하는 AI 개발 도구에 대응하면서 기존 로컬 AI 환경을 반복적으로 재구축하지 않고, 축적한 검증 결과와 개발 이력을 보존하는 방안을 논의했다.

목표는 재현성, 변경 통제, 로컬 실행 우선 원칙을 유지하면서 실제 개발 생산성을 높이는 것이다.

## 2\. 기존 아키텍처 결정 유지

`01_Local_AI_Architecture/decisions/2026-10-11_local-ai-architecture-baseline.md`에 기록된 기존 아키텍처를 기준으로 유지한다.

- Windows 네이티브 개발 환경을 유지한다.
- 로컬 추론 실행 환경으로 Ollama를 유지한다.
- 주력 코딩 에이전트로 Aider를 유지한다.
- 새로운 도구나 버전이 출시되었다는 이유만으로 아키텍처를 변경하지 않는다.
- 대체 도구 도입은 실제 검증 근거를 확보한 후 결정한다.
- 검증된 사실, 가설, 계획 및 미검증 항목을 명확하게 구분한다.

이번 논의는 기존 아키텍처 기준 결정을 대체하거나 변경한 것이 아니다.

## 3\. 코딩 에이전트 평가 방향

| 도구 | 현재 역할 | 결정 상태 |
|---|---|---|
| Aider | 주력 코딩 에이전트 | 기준선으로 유지 |
| cecli | Aider 대체 후보 | 후보 추가 제안. 검증 미완료 |
| OpenCode | 보조 후보 | 기존 평가 보류 조건 유지 |
| Jan.ai | 별도 로컬 AI 환경 평가 대상 | 평가 예정. 대체 도구로 채택하지 않음 |
| Cline / Kilo Code | 비교 및 참고 도구 | 구체적인 필요성이 있을 때 평가 |

cecli를 대체 후보로 추가하는 것은 설치, 테스트 또는 실제 도입을 완료했다는 의미가 아니다.

OpenCode v2 검토는 별도의 진단 범위와 진행 승인이 정해질 때까지 보류한다.

## 4\. 제안하는 운영 정책

1. 업그레이드 전에 릴리스 변경 사항과 호환성을 확인한다.
2. 일반 업데이트, 호환성 검증 및 아키텍처 변경을 별도의 의사결정 단계로 구분한다.
3. 기존 환경의 구체적인 한계를 해결하거나 측정 가능한 개선을 제공하는 경우에 대체 도구를 평가한다.
4. 기존 개발 환경에 영향을 주지 않도록 가능한 경우 격리된 환경에서 평가한다.
5. 동일한 기준 작업과 허용된 파일 범위를 사용하여 도구를 비교한다.
6. 재현 가능한 명령, 실행 결과, 테스트 결과 및 관련 Git 변경 사항을 기록한다.
7. 실제 결과를 확인하기 전에는 작업 성공을 선언하지 않는다.
8. 별도 승인이 없는 한 기존 문서, 백업, 실험 자료 및 미추적 기록을 보존한다.

## 5\. 향후 평가 기준

대체 도구를 평가할 때 다음 항목을 확인한다.

- 코드 변경의 정확성과 품질
- 관련 테스트의 실행 여부 및 결과
- 허용된 파일 범위 준수 여부
- 기존 Ollama 모델 및 로컬 환경과의 호환성
- 설치, 유지보수 및 장애 복구에 필요한 노력
- 수동 수정 시간을 포함한 전체 작업 소요 시간
- 비용, 개인정보 보호 및 외부 서비스 의존성

기능 목록이나 릴리스 발표만으로 주력 도구 교체를 결정하지 않는다.

## 6\. 후속 작업 계획

1. cecli의 최신 프로젝트 상태, 릴리스, 라이선스, 보안 고려 사항 및 Ollama 호환성을 조사한다.
2. 기존 환경을 변경하거나 설치를 진행하기 전에 통제된 평가 계획을 수립한다.
3. 동등한 작업 조건으로 후보 도구를 비교하고 재현 가능한 결과를 기록한다.
4. 새로운 근거가 영향을 주는 공개 후보 검증 현황을 검토한다.
5. 별도의 근거 기반 결정으로 변경 필요성이 확인된 경우에만 아키텍처 기준 문서를 수정한다.

## 7\. 검증 상태 및 한계

- 운영 전략 논의: 본 문서에 기록
- 기존 아키텍처 기준: 유지
- cecli 설치 및 실제 평가: 이번 논의에서 수행하지 않음
- OpenCode v2 검토: 보류 상태 유지
- Jan.ai 대체 도구 평가: 미완료
- 아키텍처 전환: 승인되지 않음
- 기존 아키텍처 문서, 도구 설정 및 공개 초안: 본 이력 작성 작업에서 변경하지 않음

이 문서는 2026-10-15에 논의한 계획과 방향을 기록한다. 후보 도구의 실제 테스트나 제안된 평가 정책의 구현 완료를 의미하지 않는다.
